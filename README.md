# Billes

**edFinTech intergénérationnelle avec IA embarquée.** *Donner des billes* à un proche, c'est lui donner les moyens et les clés pour s'en sortir : Billes transforme un coup de pouce financier en apprentissage partagé.

Projet 1 Innovation IA · MBA2 IA & Transformation des organisations · Epitech · Groupe Billes

> Service fictif. **Aucun compte réel, aucune donnée bancaire réelle, aucun paiement réel**, et aucune donnée personnelle réelle envoyée à un outil d'IA.

## Règles de travail

- **Une source par contenu.** Les textes longs (A, D) restent dans le document partagé. L'architecture, le backlog, le suivi et le POC vivent ici.
- **Chacun contribue sous son propre compte**, pour que le livrable F s'appuie sur des preuves. Créer ou commenter une issue, ou modifier un fichier depuis le site, suffit.
- **Une tâche, une issue**, rattachée à un jalon et à un livrable.
- **Aucune donnée réelle dans le dépôt.** Les notes d'entretiens sont anonymisées avant d'être ajoutées.
